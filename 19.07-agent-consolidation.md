## 2. Faktyczna architektura przed

```
POST /chat/turn
 → auth_middleware (session/API key + ownership)
 → chat_api → ChatRuntime.run_turn
 → ChatTurnApplicationService (idempotency + session lock + TurnContext)
 → TurnOps.run_turn_core / mixins.pipeline (duży orchestrator dict `g`)
     ├ read MemoryV2 + PsycheV2 + (opcjonalnie) legacy STM/psyche_core
     ├ pragmatics + cognitive_integration → decision_pre_exec
     ├ StrategySelector (+ policy/experience/AL/WK adjustments)
     ├ blocker → web prefetch → provider/tools LUB agent handoff (executive_controller)
     ├ persona/critic + ActionClaimGuard (WK)
     └ write-backs: transcript, experience, psyche evolve, AL, WK, durable jobs
```

Równolegle (konkurencyjne / legacy):

- Memory V1 HTTP (`/memory/add|search`) + `memory_nodes` / FTS
- `knowledge_graph` (nodes/edges puste) vs `world_knowledge` (wk_* z danymi)
- Psyche V1 (`psyche_state` via psyche_engine/core) vs Psyche V2
- Planner → task_graph wewnątrz executive; goals table pusta; WK execution_graphs osobno; AL `long_horizon_tasks`
- Unmounted `aihub/api/*` (poza security/self-heal)
- AppShell (`/admin`) + ChatShell (`/`)

## 5. Mapa migracji (kolejność wdrożenia)

1. **Pipeline / Decision** — jedna faza adjustments + wspólny finalize dla fallback i happy path.
2. **Memory** — `AIHUB_DISABLE_LEGACY_MEMORY_V1_HTTP=1`; Memory V2 jedyny strukturalny zapis osobisty.

5. **Agent/Exec** — handoff agentic ↔ `wk_execution_graphs` (create/resume/finalize).
6. **Tools/Guard** — ActionClaimGuard po critic; szersze PL/EN claims + evidence.
7. **Learning** — read→influence przez AL już w decision; decay w workerze.
8. **Dead code archive** — routery/workers/middleware.
9. **Frontend** — ChatShell kanon; admin only AppShell; drop orphans.
10. **DB retention** — consolidation worker: event_log + psyche_v2_events.
11. **Config/deploy** — `ENV=production` + vault key; Caddy → `:3001`; hardening FS/snapshot.
12. **Git freeze** — commit aktywnego drzewa.

```

## 12. Final agent / planner / execution

```
agentic handoff
 → resume_execution(egid)? 
 → ExecutiveController.run_cycle(force_strategy, execution_graph_id, LHT, session, turn)

 → _bind_wk_execution_graph (create or resume wk_execution_graphs)
 → execute plan
