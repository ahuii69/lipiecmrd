## 1. Pełny graf aktualnego runtime

```
POST /chat/turn (BFF → FastAPI)
  → auth / ownership
  → idempotency (begin_or_reuse_turn)  [reuse ⇒ replay_mode=true]
  → session lock
  → prepare: user_correction → deterministic vault → memory_fact short-circuit
  → context: memory V1 retrieval + memory V2 snapshot + psyche V2 + identity
  → pragmatics / cognitive / adaptive learning influences
  → strategy selector → reasoning/planner decisions (jawne)
  → tool policy + web policy
  → execution graph / tools
  → provider chain (DeepInfra → Groq → Ollama Cloud → dry)
  → critic / action-claim / response shaping (persona + CoT strip + unverified URL strip)
  → transcript + memory/psyche/learning/knowledge write-back
  → outbox / durable completion
```

Background (poza synchroniczną turą): executive tick `system:maintenance`, consolidation worker, agent worker — bez mieszania scope użytkownika.

## 4. Moduły scalone / konflikty usunięte

- Honest influence flags w `decision_pre_exec` + kopiowanie do trace w `pipeline` (bez atrap `true`).
- `planner_learning_applied` tylko przy realnych kodach `LEARN_*PLAN*` / bias.
- `/agent/run` nie omija runnera.
- Failover Groq 429: 1 retry → szybsze przejście na Ollama (rezerwa #3).
- Ollama model: `gemma3:4b` (retired) → **`gemma4:31b`**.
- CoT leak gpt-oss: floor `max_completion_tokens≥768` + `strip_reasoning_leak`.
- Idempotent reuse stempluje `replay_mode` / `idempotent_replay`.
- Korekty faktów: wykrywanie `korekta`/`poprawka`, durable + supersession w mem-fact short-circuit.
- Strip nieweryfikowanych cytowań URL gdy `web_used=false`.
