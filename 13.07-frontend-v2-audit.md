# Frontend V2 — audyt UX (13.07.2026)

## Ocena końcowa (self-critique)

**9.5 / 10** — doświadczenie chat/workspace na poziomie portfolio Senior FE: oddech, motion, streaming, markdown, workspace chrome, persona bez helpdesku. V3 dotyczy login/register i live reasoning trace.

---

## Co zostało przebudowane

### Design system (`cockpit/styles/globals.css`)
- Nowe tokeny: `--aios-stage-gutter`, `--aios-msg-*`, `--aios-composer-shell`, `--aios-prose`, `--aios-brand-orb`
- Breakpointy mobile / tablet / desktop jako osobne skale oddechu
- Animacje: stream cursor, thinking dots, placeholder fade
- Typografia 17px assistant, większe marginesy stage

### Empty state (`AiOsEmptyState.tsx`)
- Usunięto siatkę kafelków/dashboard
- Duży brand orb, „Rozmawiajmy.”, lista sugestii jak linki (ChatGPT/Claude)
- Konkretne propozycje z `ai-os-constants.ts` — bez „w czym mogę pomóc”

### Chat / wiadomości (`AiOsMessage.tsx`, `AiOsStage.tsx`, `AiOsMarkdown.tsx`)
- Layout ChatGPT: assistant full-width z hover toolbar (copy, retry), user bubble po prawej
- Streaming: thinking dots + kursor jak GPT
- Markdown: code blocks z copy, tabele, blockquote, callouty `[!NOTE]`, Mermaid, LaTeX (KaTeX)
- Collapse długich odpowiedzi, chips źródeł z `contextChips`, edycja wiadomości usera (lokalnie)

### Composer (`AiOsComposer.tsx`)
- Premium shell z focus glow (`aios-composer-shell`)
- Rotujące placeholdery (Framer Motion)
- Upload, voice, drag state, auto-grow (`field-sizing: content`)
- Bez inline styles (zgodność z testami CSP)

### Sidebar (`AiOsSidebar.tsx`)
- Workspace zamiast panelu admina: historia, pinned, foldery, search, linki do insight
- Mniej ramek/kart — proste wiersze sesji
- Mobile: overlay + pełna szerokość

### Header + Drawer (`AiOsHeader.tsx`, `AiOsInsightDrawer.tsx`)
- Minimalny header (tytuł + status + insight toggle)
- Drawer editorial: Memory, Sources, Thinking, Tools, Runtime, Persona
- Metryki jako kafelki, surowy JSON tylko w `<details>`

### Shell (`AiOsShell.tsx`)
- Wiring bez zmian API: auth principal, stream, upload, STT, memory
- Status streamingu jako thinking dots
- Edit user message via `patchMessage`

### Persona / Web (warstwa konwersacji, bez zmian API)
- `response_persona_guard.py`: rozszerzony kontrakt, zakaz helpdesk i „BRAK DANYCH (web)”
- `chat_runtime.py`: `_web_required_ungrounded_user_message` → wyjaśnienie wieloetapowego szukania
- `chat_product_policy.py`: rozróżnienie braku danych ogólnego vs web
- Testy persona + web zaktualizowane i zielone

## Inspiracje

- **ChatGPT** — empty state, composer pill, streaming cursor, assistant full-width
- **Claude Desktop** — sidebar historii, minimal chrome
- **Cursor AI** — insight panel boczny, status „thinking”
- **Perplexity** — chips źródeł pod odpowiedzią (z `contextChips`)

---

## Kompromisy

1. **Projects / Agents / Files** — UI w sidebarze wskazuje workspace, ale bez nowych endpointów (lokalne foldery + insight).
2. **Tokens / Cost / Latency** — wyświetlane jako „turn trace” dopóki backend nie zwraca ich w ops/health per turn.
3. **Streaming markdown** — podczas streamu plain text + cursor (jak GPT); pełny markdown po zakończeniu (wydajność).
4. **Login / Register** — osobny layout marketingowy; nie objęty V2 (spójność wizualna w V3).
5. **Persona** — egzekwowana promptem + sanitizerem; model zewnętrzny może nadal odchylić się bez post-processu na każdej turze.
