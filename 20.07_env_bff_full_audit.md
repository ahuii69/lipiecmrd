## 3. Front ↔ back (BFF)

```text
Browser :3001
  → /api/aihub/[...path]  (route.ts + classifyBffRoute + allowlist)
  → FastAPI :8080
```

### Znaleziska połączenia

#### F-BFF-1 — `GET /chat/file/{file_id}` poza allowlistą

| Pole | Wartość |
|------|---------|
| STATUS | **[A]** (naprawione) |
| dowód | `ChatMarkdown.tsx` ładuje `/api/aihub/chat/file/…`; endpoint w `chat_api.py`; **brak** w `cockpit-proxy-allowlist.json` przed fixem |
| wpływ | wygenerowane / uploadowane pliki nie przechodzą BFF po deployu z deny-by-default |
| fix | wpis allowlist + `CANONICAL_HTTP_ROUTES` + testy gate/policy |

#### F-BFF-2 — `capabilities/execute` jako admin

| Pole | Wartość |
|------|---------|
| STATUS | **[A]** (naprawione) |
| dowód | `bff-route-policy.ts` ADMIN_TEMPLATES zawierał `POST /chat/capabilities/execute`; ChatDrawer woła `memory.search` / `web.ingest_url` / `memory.add_fact` przez ten endpoint |
| wpływ | zwykły user → **403 admin role required** na akcjach Drawera |
| fix | execute = **user**; override sensitive mutations nadal admin-only w `chat_api.py` |

#### F-BFF-3 — Dual timeout file vs process

| Pole | Wartość |
|------|---------|
| STATUS | **[B→E]** |
| dowód | `cockpit/.env` 45s vs live 120s vs `route.ts` `max(base, 120000)` dla `/chat/turn` |
| fix | plik `.env` ustawiony na 120000 |

#### F-BFF-4 — Allowlist coverage (pozostałe)

| Path | Allow | Class |
