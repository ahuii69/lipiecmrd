## ETAP 6 — Runtime: wyjątki / puste returny

Spis w `aihub/**/*.py` (skan, bez `.bak`):

### Klasyfikacja wzorców (reprezentatywne, z dowodem)

| Miejsce | Wzorzec | Ocena |
|---------|---------|--------|
| `pipeline.py` mosty V2/cognitive/psyche | `except Exception` + debug + kontynuacja | **świadoma degradacja** (+ dług observability) |
| `prompt_context._build_context` pack fail | `logger.warning` + `memory_read_errors` | **świadoma degradacja** z śladem |
| `prompt_context._apply_persona_guard` | `except` + `logger.debug` skip | **defense-in-depth** (nie psuje tury) |
| `ChatRuntime.__init__` provider refresh | `except` + debug skip | **defense-in-depth** |
| `provider_service` JSON args parse | `except` → `{"_raw": args}` | **świadoma degradacja** tool-args |
| `provider_service` failover loop | catch → classify → next provider | **świadoma degradacja** / failover |
| `normalize` → `extract` → `""` dla dict bez liści tekstu | return empty | **kontrakt extract** (nie maskowanie pól); przy non-text structured → **raise retryable** |
| `extract_assistant_text` `return ""` | brak tekstu | **by design**, nie scrub historii |
| `chat_api.chat_turn` `except Exception` → HTTP 500 | propagacja | **nie maskowanie** |
| `pipeline` writeback policy fail L1157 | setdefault standard + continue | **świadoma degradacja** |

**Werdykt ogólny:** dominuje **świadoma degradacja subsystemów** i **DiD**. Klasyczne **maskowanie user-facing runtime dump** — **nie** potwierdzone w obecnym kodzie normalize/extract (**E** względem starej tezy).  
**Bug [A]** typu „except połyka krytyczny błąd providera i zwraca OK z fałszywym tekstem” — **nieudowodniony** w tym audycie na ścieżce provider (failover + dry fallback są jawne).
