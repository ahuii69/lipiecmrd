## Zachowane przepływy backendowe

| Przepływ | Implementacja |
|----------|---------------|
| Login / register / logout | `POST /api/aihub/auth/*`, cookie `aihub_session`, CSRF |
| `principal.user_id` | `useAuthPrincipal`, `cockpit-store.authUserId` |
| Listowanie sesji | `apiClient.getSessions` |
| Nowa rozmowa | `createSession` w store + sync |
| Historia | `useSessionHistoryFromServer`, GET history |
| Wysyłanie / streaming | `streamChatTurn`, `chat-turn-stream.ts` |
| Retry | `retryPayloadForLastFailedMessage`, composer retry |
| Upload | `uploadChatFile`, draft attachments |
| STT / voice | mikrofon w `ChatComposer` |
| Pamięć | drawer + sidebar link, `getMemoryV2Summary` |
| Źródła | chips z `contextChips` w odpowiedzi |
| Ownership 403 | `formatChatTurnErrorMessage` → przyjazny komunikat |

**Nie zmieniano:** endpointów, payloadów, signed principal, formatu streamingu, pamięci backendowej, web research, upload/STT API.
