## 3. Kanoniczny graf runtime

```
POST /chat/turn (chat_api → chat_runtime → TurnOps.run_turn_core)
  _stage_prepare
    → try_deterministic_turn / try_memory_fact_read_turn (short-circuit)
    → memory V1 brief (memory_core) + Memory V2 bridge + Psyche V2 + Identity bridge
    → pragmatics + cognitive pack (system_context)
  _stage_decision_blocker
  _stage_handoff (agentic → executive_controller — tylko gdy handoff)
  _stage_web_setup (controlled web prefetch)
  _stage_provider_loop
    → ProviderExecutionService.execute (DeepInfra → Groq)
  _stage_writeback (memory/psyche/learning/knowledge/experience)
```

Jedyny failover loop: `aihub/turn/provider_service.py:L377-484`.
